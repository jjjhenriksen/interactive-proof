## Retained regression coverage

- `tests/verification/lean-integration.test.ts` builds temporary full packages, compiles the imported dependency to `.olean`, and exercises the actual verifier CLI and saved verification record. `LEAN_PATH` is scoped to that child process.
- `tests/verification/fixtures/Names.lean` includes Greek/subscript, symbol-like Unicode, prime-suffixed, quoted-space, unnecessarily quoted ASCII, and qualified quoted components containing dots and an apostrophe. Matching preserves namespace component boundaries.
- `tests/verification/fixtures/Literals.lean` includes nested block comments, escaped quotes, raw strings, a character literal, admission-like identifiers, and fake audits in prose. A real audit with interleaved/trailing comments is still discovered.
- `tests/verification/fixtures/Admissions.lean` contains both real admission forms. `Foundations.lean` demonstrates `propext`, `Classical.choice`, and `Quot.sound`; all three remain allowed and visible in the report.
- `tests/evaluation/live-results.test.ts` covers provider error/failed/incomplete events, missing completion, invalid citations, errors after completion, thrown provider requests, mixed selected sets, successful completion, and sanitized metadata retention.
- `tests/evaluation/live-command.test.ts` exercises the actual CLI and SDK against a loopback-only fake provider. It checks exit status and saved metadata for the three reported failures and a passing control.
